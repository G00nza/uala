# Ualá — Documentación técnica

Plataforma de microblogging desarrollada en Go como kata técnica. Permite publicar tweets, seguir usuarios y ver un timeline personalizado optimizado para lecturas a escala.

## Páginas

- [Arquitectura](Arquitectura) — visión general del sistema, capas y flujos principales
- [Decisiones de diseño](Decisiones-de-diseño) — ADRs y trade-offs clave
- [Observabilidad](Observabilidad) — métricas, Prometheus y Grafana
